This Repository contains all the documentation of the SPARROW project group's software setup and codes
The SPARROW paper document is included for anyone who is interested to read further regarding our project


SPARROW, in conjunction with SOAR, were UCF Senior Design project groups that were sponsored by Lockheed Martin to create a drone and base station project where the drones would utilize AI for human detection and send the data over to the base station where the images would be displayed.
